# Vanguard Global Logistics (VGL) — Next-Gen Intermodal Freight & Supply Chain Platform

> **Live Preview (Penta-Websites)**: [https://penta-websites.github.io/Logistics/](https://penta-websites.github.io/Logistics/)  
> **Live Preview (Pixel-Force)**: [https://pixel-force.github.io/Logistics/](https://pixel-force.github.io/Logistics/)

Vanguard Global Logistics (VGL) is a modern, responsive corporate logistics and freight forwarding web platform inspired by premium enterprise WordPress themes (Transgo, MoversCO, Cargo, Fastrans). Engineered with high-performance semantic HTML5, modern CSS3 variables, and vanilla ES6+ JavaScript.

---

## 🚀 Key Features

- **Dual Interactive Hero Console**:
  - **Live Waybill Tracking**: Enter any Master Waybill (AWB / B/L / Container No.) or click live demo presets (`VEX-8924-US`, `VEX-1042-DE`, `VEX-5581-SG`, `VEX-3390-AE`) to inspect milestone progression, transit checkpoints, and customs stamps.
  - **Instant Freight Estimator**: Real-time rate approximation across air, ocean, and overland modes based on origin, destination, and gross weight.
- **Dedicated Service Portals**:
  - `air-freight.html`: Scheduled block space, charter aircraft specs (B747-8F, B777F, A330-300P2F), and Next-Flight-Out (NFO) prioritization.
  - `ocean-freight.html`: Full Container Load (FCL 20ft, 40ft, 40ft HC, 40ft Reefer) and Less-than-Container Load (LCL) consolidation across transpacific, transatlantic, and Europe-Asia sea lanes.
  - `road-transport.html`: GPS-telematics road haulage, dry vans, multi-temp reefers, heavy haul low-beds, and green rail intermodal corridors.
  - `warehousing.html`: Automated 3PL fulfillment, bonded Free Trade Zone (FTZ) storage, and cloud WMS API integrations.
- **Dedicated Interactive Consoles**:
  - `tracking.html`: Dedicated real-time SatNet tracking console with interactive waybill query and electronic bill of lading (e-BL) PDF download simulation.
  - `quote.html`: Comprehensive 5-step Request for Quote (RFQ) engine with volumetric calculations, bunker fuel surcharges, customs brokerage, cargo insurance, and reference ID modal generator.
  - `network.html`: Interactive global port directory covering 160+ connected terminals across the Americas, EMEA, and APAC.
  - `case-studies.html`: Detailed supply chain transformation studies with quantifiable metrics and client testimonials.
  - `about.html`: Corporate governance, executive leadership team, and accredited ISO 9001:2015, IATA, FIATA, and C-TPAT standards.
  - `contact.html`: 24/7 Operations Control Center (OCC) hotline dispatch, regional branch contacts, and instant inquiry form.

---

## 🛠 Tech Stack

- **Frontend**: HTML5, Modern CSS3 with Custom Properties (CSS variables), Vanilla ES6+ JavaScript.
- **Zero Heavy Dependencies**: 100% lightweight, lightning-fast performance, zero external framework overhead.
- **Responsive Ergonomics**: Mobile off-canvas navigation drawer, adaptive grids, and high-density retina SVG vector icons.
